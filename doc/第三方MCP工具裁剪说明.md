# 第三方 MCP 工具裁剪

## 背景

第三方 MCP 服务通常会提供一组面向通用场景的工具，而业务应用只会用到其中一部分。以本项目接入的阿里云天气 MCP 为例，服务端包含多种天气和环境查询工具，差旅问答和行程规划并不需要全部能力。

将全部工具注册给 Agent 会带来两个直接影响：

1. 工具越多，模型需要比较的名称、描述和参数越多；相似工具容易造成选择错误或重复调用。
2. 工具定义会作为模型可用能力的一部分进入请求上下文，工具描述和参数越多，通常消耗的输入 Token 越多，调用成本也会增加。

因此，项目在 MCP 客户端成功连接后，还应根据业务场景建立工具白名单，只把当前 Agent 真正需要的工具注册到它的 Toolkit。

## 项目实现

天气 MCP 白名单由 `corp.trip.weather-mcp.enabled-tools` 配置。当前配置位于 `src/main/resources/config/application.yml`：

```yaml
corp:
  trip:
    weather-mcp:
      enabled-tools: 城市天气实况,城市15日预报,城市天气预警,城市空气实况,城市24小时预报,城市40日预报
```

`GeneralInfoAgent` 和 `ItineraryPlanningAgent` 都读取这份配置，并通过 AgentScope 的 MCP 注册接口将白名单传给 `enableTools(List<String>)`。只有名单中的 MCP 工具会注册到对应 Agent；项目自定义的 Java 工具按原有方式独立注册，不受这份天气 MCP 配置影响。

相关实现：

- `src/main/java/cn/lwccxy/trip/agent/GeneralInfoAgent.java`
- `src/main/java/cn/lwccxy/trip/agent/ItineraryPlanningAgent.java`
- `src/main/java/cn/lwccxy/trip/agent/config/CorpTripAgentMcpConfig.java`

## 白名单维护

新增或删除天气 MCP 能力时，按以下步骤维护：

1. 从 MCP 服务端工具列表确认实际工具名称，并核对描述、输入参数和返回内容。
2. 按差旅业务实际任务判断该工具是否必要。例如，查询出发当天的天气可使用实况或短期预报；只有业务确实需要时，再开放空气质量、预警或较长期预报工具。
3. 将需要启用的工具名称写入 `enabled-tools`，使用逗号分隔。名称必须与 MCP 服务端公布的名称完全一致，不要使用模型提示词中的别名或自行翻译的名称。
4. 重启应用并检查 Agent 注册及 MCP 调用日志，确认启用的工具可见、可调用；同时检查不在名单中的工具没有暴露给该 Agent。
5. 如果 Agent 的系统提示词列举了天气工具名称，同步更新提示词，确保说明与实际注册工具一致。

建议按 Agent 的职责分别审核工具需求。若将来不同 Agent 需要不同的天气工具集合，应拆分为职责清楚的配置项，而不是不断扩大一个所有 Agent 共用的列表。

## 空配置行为

AgentScope 的 `enableTools` 在空名单时表示不做白名单过滤，可能会注册服务端的全部工具。因此本项目在名单为空或天气 MCP 客户端不可用时会跳过天气 MCP 注册，并输出警告日志。不要为了“默认启用全部工具”而把空名单传给 `enableTools`；需要扩大能力时，应明确填写并评审工具名称。

这也意味着配置缺失时 Agent 不具备天气 MCP 能力。调用方应将其视为天气工具未启用，并按 Agent 提示词如实说明，而不能假设会自动回退到完整工具集。

## 安全与成本边界

工具裁剪用于缩小模型可见的能力集合、减少工具选择空间和工具描述 Token，不等同于服务端权限控制。MCP 服务端及业务服务仍需自行落实身份校验、授权、限流和审计；如果将来接入可写入或有副作用的工具，不能仅依赖 Agent 工具白名单保护业务数据。

白名单也不保证总 Token 或费用按工具数量线性下降。实际收益还取决于工具描述和参数 Schema 的长度、模型调用次数、上下文历史以及供应商计费方式。上线前可通过模型用量日志对比裁剪前后的输入 Token、工具选择成功率和任务完成情况，再决定是否进一步增删工具。

## 验证清单

- [ ] 配置中的每个名称都能在第三方 MCP 工具列表中找到。
- [ ] `GeneralInfoAgent` 和 `ItineraryPlanningAgent` 均只注册配置中列出的天气工具。
- [ ] 白名单中的工具可以完成对应天气查询；不在名单中的工具不会被 Agent 调用。
- [ ] 移除某项工具后，相关提示词和业务流程没有继续要求 Agent 调用它。
- [ ] 空配置时天气 MCP 不会全量注册，Agent 能明确报告天气工具不可用。
- [ ] 通过模型用量记录和真实任务验证工具裁剪效果及对结果质量的影响。
