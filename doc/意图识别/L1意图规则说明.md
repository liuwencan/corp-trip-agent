# L1 意图规则

L1 在本地执行，不调用模型或向量库。规则集中在 `IntentType`，匹配条件由 `IntentRule` 实现。每个业务意图可以配置多条规则，每条规则由一个正向正则和零个或多个排除正则组成。

```java
new IntentRule("报销|发票|票据", "政策|标准|额度")
```

这条示意规则中，正向条件任意分支命中，且所有排除条件均未命中，规则才有效。排除条件只影响当前子句中的当前规则，不影响同意图的其他规则或其他子句。实际配置采用更具体的业务表达，避免把“订符合标准的酒店”等条件误当作排除理由。

## 业务边界

| 意图 | 主要正向表达 | 需要排除或区分的表达 |
| --- | --- | --- |
| `TRAVEL_POLICY_QUERY` | 差旅制度、住宿/交通/餐饮标准、报销上限、能否报销、给不给报商务舱、能报销多少 | “按住宿标准订酒店”是预订条件，“这笔实际报销金额”不直接当政策 |
| `TRAVEL_INFO_QUERY` | 天气、气温、城市概况、历史背景、景点介绍、当地交通信息 | 交通资源搜索、门票搜索和餐饮安排不使用宽泛名词兜底 |
| `CREATE_TRIP_APPLICATION` | 提交/创建/发起/填写或“开一张”新的出差申请 | 已提交的历史申请、已有申请查询/修改/取消、审批状态/结果、被否定的新建动作 |
| `TRIP_APPLICATION_QUERY` | 查询本人已有出差申请单/行程单的列表、详情或申请单状态，包括“看看我的申请记录”“把行程单发我” | 审批进度/审批结果/驳回原因；机票、酒店、车票等供应商订单查询 |
| `TRIP_APPLICATION_ACTION` | 修改、变更、取消、撤销或重新提交已有出差申请单/行程单 | 被否定的申请单操作；审批通过/驳回等审批动作；取消酒店、机票、车票等供应商订单 |
| `TRAVEL_RESOURCE_QUERY` | 查询、搜索、查找、比较航班/机票、高铁/火车/车次、酒店/住宿、门票等可用资源；并列句可省略重复的查询动词；路由到 `ItineraryPlanningAgent` | 完整行程规划、政策查询、已有订单、预订/取消动作、报销发票、被否定的搜索 |
| `PLAN_ITINERARY` | 规划完整行程、路线、交通住宿组合和日程 | 单独查询或比较航班/车次/酒店候选、政策查询、已有订单、预订/取消动作、报销发票、被否定的规划 |
| `BOOK_TRAVEL` | 预订/订/购买……机票或酒店、把航班订下来；“合适的话就替我订”可承接前句资源查询 | 否定预订、已有订单、退改取消、报销操作和政策查询；不把“不用付款”直接等同于“不用预订” |
| `CANCEL_BOOKING` | 明确要求取消/退订/退票已有酒店、机票、航班、车票等供应商订单，包括“退已买的机票”；并路由到 `BookingAgent` | 订单查询、改签、询问是否能退或如何退、出差申请单/行程单动作、政策标准、被否定的取消动作 |
| `APPROVAL_QUERY` | 审批进度、审批状态和结果、审批记录、驳回原因；未出现“审批”但明确询问申请流转到哪一步也归此类 | 明确要求通过、驳回、拒绝、同意、催办等审批动作 |
| `REIMBURSEMENT` | 报销、报销流程、材料、凭证、发票、票据 | 报销政策/标准、能否报销、报销额度，以及明确预订动作中的报销资格条件 |

`CHAT` 继续使用完整问候句特判；`UNKNOWN` 不注册关键词规则，未命中交给后续识别层。

## 正则写法

`规划.{0,24}行程` 可以匹配“规划行程”“规划一下下周北京的行程”。实际规则使用有限长度间隔，在允许修饰语的同时限制跨度；需要新增表达时，也可以使用 `|`、分组、可选项或其他 Java 正则语法。正向与排除正则都在规则初始化时预编译，每次识别创建独立的匹配器。

## 汇总与限制

输入先按标点和连接词拆句。L1 按诉求顺序保留并去重有效意图；各业务子句都能唯一确定时，直接返回 L1 意图列表，其中多个意图保留为有序多意图结果。仅完整问候子句可与业务诉求并存；其他未识别子句、单句多意图冲突或无命中，继续走 L2、问题改写及 L3 流程。

例如“查住宿标准，再订符合标准的酒店”保留政策与预订两个候选，排除词不会跨子句生效。“不用再订酒店”保留否定词与动作，不会因“再”拆句而误命中预订。

相邻子句满足明确条件时才补全省略。例如“查北京天气和去北京的高铁车次”共享查询动作；“查机票，合适就替我订一张”作为条件预订合并为 `BOOK_TRAVEL`；“查航班，再把合适的一班订下来”则保留 `TRAVEL_RESOURCE_QUERY` 和 `BOOK_TRAVEL` 两个顺序意图。正则不能跨任意子句补全动作和对象，引用、背景、复杂指代与多重否定仍交给后续层判断。

明确的范围外诗歌、歌词、小说、散文和故事创作请求可由 L1 直接判为 `UNKNOWN`，避免为可确定的范围外请求等待模型兜底；涉及差旅、旅行、行程、交通或住宿内容时不触发该规则。其余无法由规则确定的范围外问题仍进入后续识别层。新增规则时应同步添加正常命中、排除命中、近义表达和完整识别链路回归样例。

回归测试位于 `src/test/java/cn/lwccxy/trip/agent/intent/IntentRecognizerL1Test.java`，不依赖数据库和外部模型。
